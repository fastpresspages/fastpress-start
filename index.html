Questions

Before you fork.

Is FastPress Start really free?

Yes. The template is Apache-2.0. Use it for a personal or commercial launch. No account, no email gate, no attribution required. A link back is nice, not required.

Do I need a build step?

No. It is one HTML file, one CSS file and one JavaScript file. Open it in a browser or serve the folder with any static host. GitHub Pages works out of the box.

How does the form work?

The demo uses FormSubmit to send submissions to FastPress Labs. Before you publish, replace the endpoint in config.js with your own FormSubmit address or form backend. Never put a secret key in client-side code.

Will my page score A+ too?

Maybe. The live demo does. Your copy, hosting and form can change the score. Run the free LaunchGrade audit after you edit it and fix what applies to you. Do not chase 100 for its own sake.

Can I remove sections?

Yes. Remove the proof section if you do not have proof. Remove the form if you do not want email. Remove the FAQ if it does not help. Do not replace a missing section with an invented number or testimonial.
